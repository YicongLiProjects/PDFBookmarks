PDFBookmarks is a PDF reader app where you can add bookmarks to your PDF files so you can open them where you left off. You can add PDF files to the app
by opening files via a dedicated button or dragging and dropping the files into the list of all files. In the file viewer you can add or remove
bookmarks that store the page of your file, and you can edit annotate in the note editor reachable from the viewer page. All notes will be stored in a text
file bound to the PDF file.

You will need to manually install the WebView2 runtime to be able to use the app, download link: https://developer.microsoft.com/en-us/Microsoft-edge/webview2/?form=MA13LH
